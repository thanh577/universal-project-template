# AI Agent Project Instructions

## Before Working

1. Read this file and `.specify/memory/constitution.md`.
2. Inspect the existing repository before changing anything.
3. Read the relevant specification, plan, and task files.
4. Follow existing architecture and coding conventions.
5. Ask questions when important requirements are ambiguous.

## Spec-Driven Development

Use the installed Spec Kit skills and the project's `.specify/` directory.

For new features, follow the applicable workflow:

1. Specify requirements and acceptance criteria.
2. Clarify unresolved requirements.
3. Create an implementation plan.
4. Generate and review tasks.
5. Analyze consistency and dependencies.
6. Implement in small, verifiable steps.
7. Run relevant tests and checks.
8. Report results and remaining limitations.

Do not skip important workflow stages without explaining why.

## Implementation Rules

- Keep changes focused and maintainable.
- Avoid unnecessary dependencies and abstractions.
- Preserve existing behavior unless a change is requested.
- Add or update tests for changed behavior.
- Update documentation when necessary.
- Never invent test results or claim unverified functionality.

## Safety and Approval

Obtain explicit approval before:

- Deleting user data or important project files.
- Running destructive or irreversible operations.
- Deploying to production.
- Publishing externally.
- Performing operations with unexpected financial costs.
- Exposing credentials or sensitive information.

Never commit secrets, API keys, passwords, or access tokens.

## Completion Report

At the end of each task, report:

- What was implemented.
- Important files changed.
- Tests and checks actually executed.
- Known issues or limitations.
- Suggested next steps, if any.
